# Мир обуви

Приложение для заказа обуви на платформе **1С:Предприятие 8.3** (управляемые формы).
Учебный проект: УП, ПМ.02.

Торговая компания «Мир обуви» продаёт обувь через сеть магазинов. Приложение позволяет клиентам выбрать
и заказать одну или несколько пар обуви из каталога по моделям и размерам.

## Возможности

- Каталог обуви с фотографией, описанием, составом, ценой и доступным количеством по размерам.
- Поиск, фильтрация по категории и производителю, сортировка по наименованию и цене.
- Подсветка товаров, доступное количество которых (суммарно по всем размерам) не больше трёх.
- Корзина: добавление и удаление позиций, изменение количества.
- Оформление заказа с контролем остатков и чеком в отдельном окне.
- Просмотр, создание, удаление и редактирование заказов (в зависимости от роли).
- Вход только по логину из списка пользователей, пароль не требуется.
- Загрузка данных из таблиц Excel и фотографий.
- Расчёты с клиентами ведутся в рублях.

## Роли пользователей

| Роль | Возможности |
|---|---|
| Неавторизованный пользователь | просмотр каталога |
| Авторизованный пользователь | каталог с поиском, фильтрами и сортировкой, корзина, оформление заказа |
| Менеджер | то же, плюс просмотр состава заказов, создание и удаление заказов |
| Администратор | то же, плюс редактирование заказов, поступления товара, загрузка данных |

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `config/` | выгрузка конфигурации 1С в файлы (метаданные `.xml`, модули `.bsl`) и файл `MirObuvi.cf` |
| `code/` | отдельные модули форм: каталог и чек |
| `data/` | исходные данные в формате Excel: пользователи, товары, остатки, заказы, размеры |
| `resources/` | логотип, иконка приложения, фотографии обуви |
| `docs/` | документация и отчёт о выполнении задания (PDF) |

## Как развернуть

1. Создайте пустую информационную базу в 1С и откройте её в Конфигураторе.
2. Загрузите конфигурацию одним из способов:
   - «Конфигурация → Загрузить конфигурацию из файла…» и выберите `config/MirObuvi.cf`;
   - «Конфигурация → Загрузить конфигурацию из файлов…» и выберите папку `config/`.
3. Обновите конфигурацию базы данных (клавиша F7).
4. Запустите 1С:Предприятие и загрузите данные обработкой «Загрузка данных»: выберите таблицы из `data/`
   и фотографии из `resources/images/`.
5. Войдите по логину пользователя из таблицы `data/Users_import.xlsx`.

## Оформление

Шрифт Calibri. Цвета: основной фон `#FFFFFF`, дополнительный `#D2F6E7`, акцент `#70B2AF`,
подсветка малых остатков `#FF8080`. Логотип и иконка лежат в `resources/`.
